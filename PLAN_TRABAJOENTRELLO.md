## 🔄 FLUJO KANBAN — Cómo se mueve cada tarjeta

```
📚 BACKLOG
     │
     ▼
🎯 SPRINT ACTUAL
     │
     ▼
📌 TODO
     │
     ▼
🔨 DOING
     │
     ▼
👀 REVIEW
     │
     ▼
🧪 TESTING
     │
     ▼
✅ DONE
```

**Ejemplo:**

> **BE-08 - API Citas** (Asignada a Camila)
>
> 19/08 → 📌 TODO → Camila comienza → 🔨 DOING → Termina código → 👀 REVIEW → Brayan/Jhilian revisan → 🧪 TESTING → Prueban endpoint → ✅ DONE
