Ejercicio: Desarrollo de un Sistema Web para un Consultorio Médico 1. Objetivo Desarrollar una aplicación web para un consultorio médico que permita a los pacientes conocer los servicios disponibles y solicitar citas, mientras que el personal del consultorio pueda administrar pacientes, médicos, horarios y citas. El objetivo es que el estudiante no solamente diseñe una página informativa, sino que desarrolle un sistema funcional de gestión de un consultorio.  2. Página principal Crear una página de inicio moderna y profesional. Debe contener:  Logo del consultorio.   Nombre del consultorio.   Menú de navegación.   Imagen principal.   Información breve del consultorio.   Botón "Solicitar cita".   Botón "Ver médicos".  Menú  Inicio   Nosotros   Especialidades   Médicos   Servicios   Horarios  
 Contacto   Solicitar cita   3. Ejercicio 1  Especialidades Crear una sección donde se muestren las especialidades disponibles. Por ejemplo:  Medicina general.   Pediatría.   Ginecología.   Cardiología.   Dermatología.   Odontología.  Cada especialidad debe mostrar:  Nombre.   Imagen.   Descripción.   Médico especialista.   Horarios disponibles.   Botón "Solicitar cita".  Las especialidades anteriores son ejemplos para el ejercicio; el estudiante puede reemplazarlas por las que defina el consultorio.  4. Ejercicio 2  Médicos Crear una sección con los profesionales que trabajan en el consultorio. Cada médico deberá tener:  Fotografía.   Nombre.  
 Especialidad.   Descripción.   Horarios de atención.   Años de experiencia.   Botón "Ver perfil".  Ejemplo: Dra. María López  Especialidad: Medicina General Dr. Carlos Pérez  Especialidad: Cardiología  5. Ejercicio 3  Solicitar una cita El paciente deberá poder solicitar una cita mediante un formulario. Datos del paciente  Nombre.   Apellido.   CI.   Fecha de nacimiento.   Teléfono.   Correo.  Datos de la cita  Especialidad.   Médico.   Fecha.   Hora.   Motivo de consulta.  Botón: Solicitar cita 
El sistema deberá comprobar que el horario seleccionado esté disponible.  6. Ejercicio 4  Agenda médica Crear una pantalla donde el médico o administrador pueda visualizar las citas. Ejemplo: Hora Paciente Médico Motivo Estado 08:00 Juan Pérez Dra. López Consulta Confirmada 09:00 Ana García Dr. Pérez Control Pendiente 10:00 Carlos Rojas Dra. López Consulta Atendida Estados posibles:  Pendiente.   Confirmada.   Atendida.   Cancelada.   No asistió.   7. Ejercicio 5  Registro de pacientes Crear un módulo para administrar pacientes. El administrador podrá:  Registrar paciente.   Buscar paciente.   Editar información.   Consultar datos.   Ver historial de citas.  Tabla: 
Paciente CI Teléfono Fecha nacimiento Última cita  8. Ejercicio 6  Historia clínica Al seleccionar un paciente, deberá existir una opción: "Historia clínica" Mostrar información como:  Datos personales.   Antecedentes.   Alergias.   Observaciones.   Consultas anteriores.  Cada consulta podrá registrar:  Fecha.   Médico.   Motivo de consulta.   Observaciones.   Diagnóstico.   Tratamiento/indicaciones.   Próximo control.  Importante: para el ejercicio académico se debe utilizar información ficticia. No utilizar datos médicos reales de pacientes.  9. Ejercicio 7  Gestión de médicos El administrador deberá poder:  Registrar médicos.   Editar médicos.  
 Activar/desactivar médicos.   Asignar especialidades.   Definir horarios de atención.  Ejemplo: Médico: Dra. María López Especialidad: Medicina General  Lunes:     08:00 - 12:00 Martes:    08:00 - 12:00 Miércoles: 14:00 - 18:00 Jueves:    08:00 - 12:00 Viernes:   08:00 - 12:00  10. Ejercicio 8  Gestión de citas El administrador deberá poder:  Crear una cita.   Reprogramarla.   Cancelarla.   Confirmarla.   Marcarla como atendida.  Cuando se cancele una cita, el horario deberá quedar nuevamente disponible.  11. Ejercicio 9  Panel del médico Crear un panel diferente para el médico. Debe mostrar: Citas de hoy 08:00  Juan Pérez      Pendiente 
09:00  Ana García     Confirmada 10:00  Carlos Rojas   Confirmada El médico podrá seleccionar un paciente y acceder a su información clínica. Después de la consulta podrá registrar la información correspondiente.  12. Ejercicio 10  Panel administrativo Crear un dashboard para el administrador. Debe mostrar: Resumen  Pacientes registrados.   Citas del día.   Citas pendientes.   Citas atendidas.   Citas canceladas.   Médicos activos.  Ejemplo PACIENTES       245 CITAS HOY        18 PENDIENTES        7 ATENDIDAS        10 CANCELADAS        1 MÉDICOS           8  13. Ejercicio 11  Pagos Si el consultorio cobra por las consultas, crear un módulo de pagos. Registrar: 
 Paciente.   Médico.   Consulta.   Monto.   Fecha.   Método de pago.   Estado.  Métodos:  Efectivo.   QR.   Transferencia.   Tarjeta.  Estados:  Pagado.   Pendiente.   Anulado.   14. Ejercicio 12  Reportes Crear una sección de reportes. El administrador podrá consultar:  Citas por día.   Citas por mes.   Citas por médico.   Citas por especialidad.   Pacientes nuevos.   Consultas atendidas.   Cancelaciones.   Ingresos.  Permitir filtros por:  Fecha.  
 Médico.   Especialidad.   Estado de la cita.   15. Ejercicio 13  Contacto La página pública deberá mostrar:  Dirección.   Teléfono.   WhatsApp.   Correo.   Horarios.   Redes sociales.   Ubicación en mapa.  También incluir un formulario: Nombre  Correo  Teléfono  Mensaje Botón: Enviar mensaje  16. Roles del sistema El sistema deberá manejar diferentes tipos de usuario. Administrador Puede:  Gestionar médicos.  
 Gestionar pacientes.   Gestionar citas.   Gestionar horarios.   Consultar reportes.   Gestionar pagos.  Médico Puede:  Ver sus citas.   Consultar pacientes asignados.   Registrar consultas.   Consultar la historia clínica necesaria para la atención.  Recepción Puede:  Registrar pacientes.   Crear citas.   Confirmar citas.   Reprogramar citas.   Registrar pagos.  Paciente Puede:  Registrarse.   Solicitar citas.   Consultar sus citas.   Cancelar una cita según las reglas del sistema.   17. Flujo principal El flujo que debe funcionar al finalizar el ejercicio será: 
PACIENTE    Ingresa a la página    Consulta especialidades    Selecciona médico    Consulta horarios disponibles    Solicita una cita    Confirma sus datos    CITA REGISTRADA    Recepción confirma    PACIENTE ASISTE    MÉDICO REALIZA LA CONSULTA    Registra información de la consulta      18. Pantallas mínimas que deben desarrollar Página pública 1. Inicio  2. Nosotros  3. Especialidades  4. Médicos  5. Servicios  6. Horarios  
7. Solicitar cita  8. Contacto  9. Login  Sistema interno 10. Dashboard  11. Pacientes  12. Médicos  13. Agenda  14. Citas  15. Historia clínica  16. Pagos  17. Reportes  18. Configuración   19. Entregable final El estudiante deberá entregar un sistema web funcional para un consultorio médico, donde exista conexión entre:  El criterio principal será que las partes no sean solamente pantallas independientes. Por ejemplo: Si un paciente reserva una cita con un médico para las 10:00, ese horario debe dejar de aparecer como disponible, la cita debe aparecer en la agenda del médico y recepción debe poder verla y confirmarla.
